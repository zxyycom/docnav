## 目的
- 保持发起验证前的原分支对工作连续性的唯一所有权。
- 避免临时验证分支引入额外合并历史或接管后续开发。

## 背景
- 为取得非本机环境证据而使用临时分支，不表示工作所有权已经迁移。
- 已验证提交需要回到原工作分支，后续修改才能沿原有历史继续。
- 本记录从 [受控验证后回归原工作分支](return-validated-commits-to-original-branch.md)中抽取工作连续性判断；当前关系模型无法表达同一前序的一旧多新拆分，因此 `relations` 有意留空。

## 决策
- 采用: 发起受控云端验证前的原分支继续拥有工作连续性；临时验证分支只承载形成证据所需的提交和远端运行。
- 采用: 云端验证成功后，在原分支以 `--ff-only` 快进到已验证提交，再从原分支继续工作。
- 不采用: 在临时验证分支长期开发，或为返回原分支创建 merge commit。
- 边界: 临时分支的删除不由本决策自动授权或要求。
